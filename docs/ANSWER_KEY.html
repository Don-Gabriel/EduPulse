Loop boundaries

Diagnostic 1B · [0, 1, 2, 3]

What does this program print?

print(list(range(4)))

A single argument is the stop. Start defaults to 0, and 4 is excluded, so the values are 0, 1, 2, 3.

Diagnostic 2C · [2, 3, 4, 5]

Which list is printed?

print(list(range(2, 6)))

The first value is 2, not 0. Stop 6 is excluded; the last value is 5.

Practice 1A · [1, 3, 5, 7]

The step is 2. What list is printed?

print(list(range(1, 8, 2)))

Start at 1 and add 2: 1, 3, 5, 7. The next value is 9, which crosses the stop boundary.

Practice 2D · []

What list is printed when start equals stop?

print(list(range(5, 5)))

The starting value already fails the below-stop condition. There are no values, so the loop would run zero times.

Practice 3B · [7, 5, 3]

The step is negative. What list is printed?

print(list(range(7, 1, -2)))

Subtract 2 each time and keep values strictly above 1: 7, 5, 3. The stop is excluded in both directions.

Independent check: which list is printed?

print(list(range(4, 11, 3)))

Begin at 4 and add 3. Values 4, 7, and 10 are below 11; the next value, 13, is not.

Retest 2A · [6, 4, 2]

Independent check: what list is printed?

print(list(range(6, 0, -2)))

With a negative step, values must remain above stop 0. That gives 6, 4, 2.

Retest 3D · []

Independent check: what happens when the default step points away from the stop?

print(list(range(9, 3)))

The default step is positive. Starting at 9 cannot move toward a lower stop of 3, so this range is empty.

Off-by-one errors

Diagnostic 1C · 4

The author wants five repetitions. How many does this program actually count?

count = 0
for i in range(1, 5):
    count += 1
print(count)

The values are 1, 2, 3, 4: four repetitions. For five repetitions, range(5) works; for values 1 through 5, use range(1, 6).

Diagnostic 2A · 3

What is the final valid nonnegative index for this list?

scores = [12, 15, 18, 21]
print(len(scores) - 1)

There are four items but indices start at zero. The indices are 0, 1, 2, 3; index 4 would be out of bounds.

Practice 1D · 6

The author wants the sum 1 + 2 + 3 + 4. What is actually printed?

total = 0
for number in range(1, 4):
    total += number
print(total)

The loop visits 1, 2, 3 and adds them to get 6. Stop 4 excludes the intended final term; range(1, 5) would include it.

Practice 2B · 3

The loop should count every item. How many items does this version count?

items = ['red', 'blue', 'green', 'gold']
count = 0
for i in range(len(items) - 1):
    count += 1
print(count)

len(items) - 1 is 3, and range(3) visits only 0, 1, 2. Subtracting one from an already exclusive stop skips the final item.

Practice 3C · [0, 1, 2]

Which list of valid nonnegative indices is printed?

names = ['Asha', 'Bilal', 'Chen']
print(list(range(len(names))))

The length is 3, so range(3) produces exactly the three valid nonnegative indices. Do not add or subtract one from this stop.

Retest 1A · 5

Independent check: the goal is to count labels 1 through 6. What is actually printed?

count = 0
for label in range(1, 6):
    count += 1
print(count)

Labels 1, 2, 3, 4, 5 are visited: five labels. To include label 6, the stop must be 7.

Retest 2D · [0, 1, 2, 3, 4]

Independent check: which list of positions is printed?

marks = [8, 9, 10, 11, 12]
print(list(range(len(marks))))

Five items have nonnegative indices 0 through 4. range(len(marks)) includes each valid index exactly once.

Retest 3B · 15

Independent check: the intention is to add 1 through 5 inclusive. What does this code print?

total = 0
for number in range(1, 6):
    total += number
print(total)

Stop 6 excludes 6 but includes 5. The visited numbers are 1, 2, 3, 4, 5, whose sum is 15.

Nested-loop execution

Diagnostic 1D · 6

How many times is the innermost statement counted?

count = 0
for row in range(2):
    for column in range(3):
        count += 1
print(count)

Each of the two outer iterations runs all three inner iterations. The total is 3 + 3 = 6, not 2 + 3.

Diagnostic 2B · [(0, 0), (0, 1), (1, 0), (1, 1)]

What list is printed?

pairs = []
for row in range(2):
    for column in range(2):
        pairs.append((row, column))
print(pairs)

The inner loop finishes columns 0 and 1 for row 0 before the outer loop moves to row 1.

Practice 1A · 6

The inner bound changes with row. What is printed?

count = 0
for row in range(1, 4):
    for column in range(row):
        count += 1
print(count)

The outer values are 1, 2, 3. They produce 1, 2, 3 inner executions, so add 1 + 2 + 3 = 6. A constant multiplication would be wrong.

Practice 2C · 0

The inner range is empty. What is printed?

count = 0
for row in range(4):
    for column in range(0):
        count += 1
print(count)

range(0) has no values. Although the outer loop runs four times, the innermost statement never executes.

Practice 3D · 3

The counter increases once after each inner loop. What is printed?

count = 0
for row in range(3):
    for column in range(2):
        pass
    count += 1
print(count)

Indentation places count += 1 outside the inner loop but inside the outer loop. It runs once per row, for a total of 3.

Retest 1C · 12

Independent check: how many inner executions are counted?

count = 0
for group in range(3):
    for item in range(4):
        count += 1
print(count)

Each of three groups has four inner iterations: 4 + 4 + 4 = 12.

Retest 2B · 10

Independent check: the inner bound changes. What is printed?

count = 0
for row in range(1, 5):
    for column in range(row):
        count += 1
print(count)

The inner loop runs 1, then 2, then 3, then 4 times. Adding those gives 10; the inner count is not fixed.

Retest 3A · [(1, 0), (1, 1), (2, 0), (2, 1)]

Independent check: which order of pairs is printed?

pairs = []
for row in range(1, 3):
    for column in range(2):
        pairs.append((row, column))
print(pairs)

Outer values are 1 and 2. For each one, the inner values 0 and 1 finish in order before the next outer iteration.
